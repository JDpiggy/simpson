What does this mean?

? How is this calculated?

Each value below is computed from your species counts:

  • n = number of individuals of one species
  • N = total number of individuals across all species (N = n₁ + n₂ + n₃ + …)
  • D = Σ[n(n − 1)] / [N(N − 1)] — add up n(n − 1) for every species, then divide by N(N − 1).
  • Index of Diversity = 1 − D
  • Reciprocal Index = 1 / D

Important: Different textbooks may call different forms “Simpson’s Diversity Index.” Some courses use D, some use 1 − D, and some use 1 / D. This calculator shows all three values so you can match whichever convention your assignment or lab manual uses.

Worked example (the sample data)

Oak 12 · Maple 8 · Pine 4 · Birch 6  →  N = 30 

Σ[n(n − 1)] = 12·11 + 8·7 + 4·3 + 6·5 = 132 + 56 + 12 + 30 = 230
N(N − 1)    = 30 · 29 = 870
D           = 230 / 870 ≈ 0.2644
1 − D       ≈ 0.7356
1 / D       ≈ 3.7826
